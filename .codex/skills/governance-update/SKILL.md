## Workflow

1. Read `AI_CONTEXT.md`, `.agents/context/*.md`, and `AGENTS.md`.
2. Identify any new stable invariant, boundary, or repeated testing rule.
3. Propose 1–3 short English snippets with exact file and section targets.
4. Ask the user to approve or reject each snippet before any edit.
5. Avoid large governance rewrites when a focused insertion is enough.
