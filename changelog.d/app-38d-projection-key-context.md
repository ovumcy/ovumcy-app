### Fixed

- **Partner updates upload again.** Ovumcy Cloud now requires each partner update to name the invite its encryption key came from; the app sends it, so partner updates no longer fail.
- **Partner shares that can no longer update ask to be renewed.** A partner share created before this change, or re-shared from another device since this one set it up, cannot receive new updates from this device. It now says so in the partner list and asks you to revoke it and send a new invite, instead of failing silently.
