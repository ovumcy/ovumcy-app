### Fixed

- **Turning on two-factor in Ovumcy Cloud now shows the new recovery code.** Ovumcy Cloud replaces the account recovery code when two-factor turns on; the app now shows that code once in the *Save this recovery code* dialog instead of leaving you with a saved code that no longer works.
- **A partner who joined from an invite link stays signed in.** The guest session now keeps the renewal token Ovumcy Cloud issues with it, so partner access no longer ends a day after accepting the invite.
