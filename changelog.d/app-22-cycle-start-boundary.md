### Fixed

- **Cycle starts follow the same rule everywhere.** A cycle now starts only on a marked non-spotting day, two consecutive non-spotting period days, or a single period day dated today or yesterday — the ovumcy-web rule. Spotting days, a lone older period day and a start flagged uncertain no longer open a cycle on their own, so cycle lengths, the calendar's recorded start and predictions can shift for histories that contain them. After a positive pregnancy test, predictions resume only from a cycle start the anchor reads too, never anchored on bleeding that began before the test.
