### Fixed

- **Turning on two-factor on a self-hosted sync server now shows your new recovery code.** The server replaces the account recovery code when two-factor setup completes; the app now shows the new code once, explains that the code from registration or your last regeneration no longer works, and never stores it. If the setup runs out of attempts, the app returns you to the password step to start again, and a wrong code explains that a setup started on another device replaces this one.
