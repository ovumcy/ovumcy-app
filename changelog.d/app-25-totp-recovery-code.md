### Fixed

- **Turning on two-factor on a self-hosted sync server now shows your new recovery code.** The server replaces the account recovery code when two-factor setup completes; the app now shows the new code once, explains that the code from registration or your last regeneration no longer works, and never stores it. If the setup runs out of attempts, the app returns you to the password step to start again, and a wrong code explains that a setup started on another device replaces this one. If the confirmation is lost on the way back, the app now says the new code never arrived instead of a plain network error. Every one-time recovery code dialog (also after a password reset or regeneration) now closes only with *I have saved it*; the system back gesture no longer dismisses it.
