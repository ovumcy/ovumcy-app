### Fixed

- A cycle start set in Settings no longer disappears when a temperature, note or symptom is logged on that day. Un-ticking, marking spotting or marking an uncertain start on the stored start date, or clearing that day, now moves the stored start to the latest cycle start on or before today (never a future-dated day). Uncertain manual marks no longer replace the stored start. Existing data is re-checked once on the first launch after the update, and again after a JSON import or a sync restore.
