### Added

- **Cycle day reminders.** In Settings, Reminders you can add up to ten reminders for a chosen day of the running cycle and a chosen hour, as on the web app. The notification text stays generic; a reminder's label is shown in the notification only if you switch that on for the reminder. Reminders are skipped while predictions are paused or the cycle is overdue. Restoring a backup file keeps the reminders but turns label display off until you switch it on again.
